# Machine Learning Algorithms

This repository contains implementations of popular Machine Learning
algorithms using Python.

## Algorithms Covered

### Supervised Learning
- Linear Regression
- Logistic Regression
- KNN
- Decision Tree
- Random Forest
- SVM
- Naive Bayes
- Gradient Boosting
- AdaBoost
- XGBoost

### Unsupervised Learning
- K-Means Clustering
- Hierarchical Clustering
- DBSCAN
- PCA

### Regularization
- Ridge Regression
- Lasso Regression
- Elastic Net

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Purpose
This repository is created for learning, practice and understanding
Machine Learning algorithms through practical implementations.
